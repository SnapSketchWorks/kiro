# 미현상 (未現像)

> 아버지의 서른세 번째 여름

사진과 AI를 취미로 하는 마흔셋 남자의 이야기를 담은 장편소설과, 그 소설을 PC·모바일에서 편하게 읽을 수 있는 의존성 없는 HTML 리더.

- **본문**: 제1권 / 4부 / 24화 + 종장
- **분량**: 공백 포함 105,750자 (200자 원고지 약 529매, 신국판 약 252쪽) · 예상 독서 약 3시간 40분
- **리더**: 다크 / 세피아 / 라이트 테마, 반응형, 읽던 위치 복원. 빌드 결과물은 **파일 하나로 오프라인 동작**

## 줄거리

아버지가 죽고 낡은 사진관을 정리하던 서진우는, 암실 바닥에서 한 번도 현상하지 않은 필름 서른일곱 통을 발견한다. 서른셋에는 같은 날짜가 적혀 있다. 8월 12일. 아홉 살 여름, 어머니가 사라진 날이다.

그는 아버지가 남긴 문장 1,140개로 아버지처럼 말하는 프로그램을 만들고, 매일 밤 그것과 이야기한다. 그 기록이 책이 되어 15만 부가 팔린다. 세상은 그것을 실화라고 믿는다 — 가장 유명한 그 문장 세 개를 저자가 새벽 4시 26분에 직접 써넣었다는 사실만 빼고.

## 리더 기능

- **각 화의 사진** — 25화마다 필름 프레임에 담긴 흑백 사진 한 장. 외부 이미지 파일 없이 SVG 필터로 그려진다. 평면 색을 쓰지 않고 그라디언트·대기 원근·피사계심도·블룸·필름 그레인으로 연속 계조를 만든다. 사진은 사진집처럼 고정 계조이며, 테마 보정은 CSS filter 로만 한다. 설정에서 숨길 수 있음
- **테마 4종** — 시스템 자동 / 라이트 / 세피아 / 다크. 첫 페인트 전에 적용되어 깜빡임 없음
- **읽기 설정** — 명조·고딕, 글자 크기 5단계, 줄 간격 3단계, 본문 폭 3단계, 사진 표시. 모두 `localStorage`에 저장
- **목차** — 권 › 부 › 화 계층, 제목 검색, 읽은 화 표시
- **이어서 읽기** — 마지막으로 읽던 화와 스크롤 위치까지 복원
- **이동** — 좌우 화살표 키, 모바일 스와이프, `T` 목차 / `D` 테마 / `C` 표지, `#12` 형태의 해시 딥링크
- **작품 정보** — 분량 · 구성 · 작품 노트 · 읽는 방법 · 피드백 경로 (`#info`)
- **접근성** — 세그먼트 컨트롤에 `aria-labelledby`, 글자 크기 버튼마다 개별 `aria-label`, 현재 화에 `aria-current`, `prefers-reduced-motion` 대응
- 스크롤 시 상단바 자동 숨김, iOS safe-area 대응, 인쇄 스타일, `prefers-reduced-motion` 지원

## 개발

```bash
node build.js              # dist/ 에 단일 파일 생성 + 분량 통계 출력
node test/harness.js       # 로직 검증 — 최소 DOM 스텁 (70개 항목)
node test/render-check.js  # 렌더 검증 — 헤드리스 브라우저로 실제 계산된 스타일 확인 (10개 항목)
```

공유 카드 이미지는 다음으로 다시 만듭니다.

```bash
node tools/make-og.js      # tools/og-card.html 을 1200x630 PNG 로 렌더
```

카드에는 제목을 넣지 않습니다. 카카오톡·슬랙·트위터 등이 `og:title`/`og:description` 을 자기 폰트로 렌더해 이미지와 함께 보여주기 때문에, 이미지에 텍스트를 구우면 제목이 중복되고 렌더 환경에 한글 폰트가 없을 때 글자가 깨집니다.

검증이 두 단계인 이유가 있습니다. 스텁 하네스는 `element.hidden = true` 를 확인하지만, CSS 에 `.cover { display: grid }` 가 있으면 화면에서는 숨겨지지 않습니다. 이런 부류의 문제는 실제 렌더 결과를 봐야 잡힙니다. `render-check` 는 계산된 스타일을 직접 읽어 다음을 확인합니다.

- `hidden` 속성이 실제로 요소를 숨기는지
- 도판 SVG 가 UI 아이콘용 `stroke`/`fill` 을 상속받지 않는지
- 도판이 본문 폭까지 커지는지
- 사진이 테마 변수에 의존하지 않고, 테마 보정이 filter 로 적용되는지

도판을 눈으로 확인할 때는 컨택트시트를 씁니다.

```bash
node test/contact-sheet.js dark                    # 25장을 한 판에
node test/contact-sheet.js light out.html only:4,11 # 특정 화만 크게
```

생성된 HTML 을 브라우저로 열거나 헤드리스로 캡처해 확인합니다. 브라우저가 없는 환경에서는 `render-check` 가 자동으로 건너뜁니다.

빌드는 `index.html`의 `<link>` / `<script src>` 를 인라인으로 치환하는 방식이며, 외부 의존성이나 패키지 매니저가 필요하지 않습니다.
